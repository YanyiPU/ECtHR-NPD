# Reproducibility

The artifact will support reproduction of the main reported tables through:

1. split files,
2. anonymized label/schema files,
3. prediction/result CSV files,
4. evaluation scripts for computing MAE, RMSE, Pearson correlation, Spearman correlation,
   zero-award metrics, and split-level summaries.

The repository is intentionally minimal during anonymous review and will be expanded
with cleaned scripts and documentation before public release.
