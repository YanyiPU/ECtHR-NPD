# Data Access

This repository does not redistribute raw ECtHR judgment text.

The review artifact is designed to provide:

- anonymized label files,
- split files,
- schema documentation,
- evaluation scripts,
- result tables.

Raw judgments should be reconstructed from public ECtHR/HUDOC sources where permitted.
Compensation-bearing text and award-bearing snippets are not included in the strict
model-facing inputs.
