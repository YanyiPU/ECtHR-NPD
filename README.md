# Anonymous Artifact Repository

This is the anonymized review-time artifact repository for the submitted ACL/ARR paper.

At submission time, this repository contains documentation for the artifact release,
data access policy, and reproduction plan. Code, split files, and result tables will
be added as the artifact is cleaned for anonymous review and camera-ready release.

## Contents

- `docs/`: data access and reproducibility notes.
- `data/`: placeholder for anonymized labels, schema files, and split files.
- `results/`: placeholder for result tables corresponding to the paper.
- `scripts/`: placeholder for evaluation and reproduction scripts.

## Data release policy

Raw ECtHR judgment texts are not redistributed in this repository. The public source
documents can be retrieved from HUDOC using case identifiers and reconstruction scripts
where permitted. The release is intended to contain anonymized labels, split files,
schemas, evaluation scripts, and result tables.

## Anonymity

Author names, affiliations, internal project paths, cloud-drive links, API logs, and
non-anonymous repository links are intentionally omitted during review.

## Citation

Citation information will be added after the review process.
