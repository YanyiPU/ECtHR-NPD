# Structured-Feature Tree Inputs

These files are optional model-ready inputs for reproducing the
structured-feature tree baselines. They are not the main dataset release.

They implement the shared prediction-input policy as serialized structured
inputs: case metadata, violated-article indicators, aggregate case/fact
features that exclude award-related material, and the log-transformed external
economic covariates.

The canonical public dataset is `data/ecthr_npd_cases.csv`.
