# Structured-Feature Tree Inputs

These files are optional model-ready inputs for reproducing the
structured-feature tree baselines. They are not the main dataset release.

They implement the shared strict input contract as serialized structured
inputs: safe case metadata, violated-article indicators, aggregate
non-compensation case/fact features, and the log-transformed external
economic covariates.

The canonical public dataset is `data/ecthr_npd_cases.csv`.
