# Path Placeholders

The package does not include local paths or credential values. Replace
these placeholders when running code:

- `your_path/strict_case_inputs.jsonl`: strict Article-41-free case text
  or serialized case inputs keyed by `itemid`.
- `your_path/ECHROD/echr_database`: local ECHR-OD/ECHROD source export for
  reconstructing public HUDOC metadata.
- `your_path/hudoc_judgments_docx`: local HUDOC DOCX download directory.
- `your_path/echrod_source_index`: local non-text ECHR-OD/ECHROD subset
  index built by `source_reconstruction/build_echrod_subset.py`.
- `your_path/extraction_workspace`: local workspace that may contain raw
  or derived judgment text generated by the reconstruction scripts.
- `your_path/or_hf_model_id`: a local encoder checkpoint path or a public
  Hugging Face model id.
- `your_path/reasoning_layer.csv`: optional strict sidecar used by the
  ReAct controller when available.
- `your_path/applicant.csv`: optional applicant sidecar used by the
  ReAct controller when available.
- `your_path/combined.csv`, `your_path/facts_procedure_scalars.csv`,
  `your_path/legal_analysis.csv`, `your_path/per_applicant_alloc_normalized.csv`:
  optional extraction sidecars for the older single-prompt controller path.
- `your_path/optional_results_audit.csv`: optional local comparison file
  for prompt-output evaluation.
- `your_api_base`, `your_api_key`, `your_model`: runtime extraction
  provider settings supplied through environment variables.

Provider credentials are read from user environment variables at runtime;
no credential values are packaged.
