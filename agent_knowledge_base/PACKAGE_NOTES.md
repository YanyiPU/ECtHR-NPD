# Agent Knowledge Base Package Notes

This is the redacted ReAct knowledge base used for the paper's
knowledge-augmented agent condition. Figure/heatmap assets and Python
bytecode are excluded. The ReAct controller code is included with local
paths and personal identifiers scrubbed; no provider credentials or API
keys are included. Empirical prior tables are train-split resources for
the agent condition, not strict tree/encoder input columns.
