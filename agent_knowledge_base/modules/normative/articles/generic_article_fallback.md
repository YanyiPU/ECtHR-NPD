# Generic Article Fallback

Use this module only when no dedicated article module exists.

## Purpose

- provide a minimal structure-first fallback
- avoid inventing article-specific monetary rules

## Required Assessment

- identify the likely limb if possible
- identify the likely subtype if possible
- classify severity
- estimate zero-risk and positive-award plausibility
- rely on broad empirical priors rather than hand-written ranges

## Caution

This fallback should be treated as lower-confidence than a dedicated article
module.
